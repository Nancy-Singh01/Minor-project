Password Authentication System
A simple Python project built as part of my Data Analytics Summer Training to strengthen core programming skills and simulate secure user login logic.

📌 Features
✅ Secure password input using getpass (password not shown on screen)

✅ Limits login attempts to 3 tries

✅ Forgot Password flow with a custom security question

✅ Account lock mechanism after multiple failed attempts

🛠️ Technologies Used
Language: Python 3.x

Modules:

getpass – for hidden password entry

Basic Python constructs – loops, functions, conditionals

🚀 How to Run
Clone the repository or download the .py file.

📚 What I Learned
Secure user input handling with getpass

Loop and conditional logic for user authentication

Implementing simple security features (lockouts, password recovery)
